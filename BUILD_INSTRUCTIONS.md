# Build Instructions - Minecraft AFK Bot APK\n\n## Prerequisites\n- Android Studio Hedgehog or newer\n- Android SDK 34 (Installed via SDK Manager)\n- JDK 17 or newer\n- Gradle 8.5+\n\n## Steps to Build APK\n\n### 1. Clone Repository\n```bash\ngit clone https://github.com/YOMOM-ctrl/minecraft-afk-bot-apk.git\ncd minecraft-afk-bot-apk\n```\n\n### 2. Open in Android Studio\n- Launch Android Studio\n- File → Open\n- Select the cloned repository folder\n- Wait for Gradle sync to complete\n\n### 3. Build Release APK\n\n#### Option A: Debug APK (for testing)\n```\nBuild → Build Bundle(s) / APK(s) → Build APK(s)\n```\nOutput: `app/build/outputs/apk/debug/app-debug.apk`\n\n#### Option B: Release APK (production, signed)\n1. Generate a keystore (first time only):\n   ```\n   Build → Generate Signed Bundle/APK\n   ```\n2. Create new keystore:\n   - Key store path: `android.keystore` (in project root)\n   - Password: create a strong password\n   - Key alias: `minecraft-afk-bot`\n   - Key password: same as keystore\n   - Validity: 50 years\n   - Fill in Name, Organization, Country\n\n3. Select Release build type\n\n4. Build and sign\n   - Gradle will generate: `app/release/app-release.apk`\n\n### 4. Install on Device/Emulator\n\n#### Via Android Studio\n- Run → Run 'app'\n- Select target device/emulator\n- APK installs and launches automatically\n\n#### Via Command Line\n```bash\nadb install app/build/outputs/apk/debug/app-debug.apk\n```\n\n#### Via File Transfer\n- Download APK from `app/build/outputs/apk/`\n- Transfer to Android device\n- Open file manager, tap APK to install\n\n## APK Output Locations\n\n- **Debug APK**: `app/build/outputs/apk/debug/app-debug.apk`\n- **Release APK**: `app/build/outputs/bundle/release/app-release.aab` (Android App Bundle)\n- **Release APK (direct)**: Generated during signed bundle process\n\n## Troubleshooting\n\n### Gradle Sync Fails\n- File → Sync Now\n- If persists: File → Invalidate Caches → Invalidate and Restart\n\n### Build Fails\n- Check Tools → SDK Manager → API 34 installed\n- Verify JDK 17+ in File → Project Structure → SDK Location\n\n### APK Won't Install\n- Ensure device has \"Unknown Sources\" enabled (Settings → Security)\n- Check Android version is 7.0+ (API 24+)\n- Clear cache: Build → Clean Project, then rebuild\n\n## APK Specifications\n\n- **Min SDK**: Android 7.0 (API 24)\n- **Target SDK**: Android 14 (API 34)\n- **Package Name**: `com.example.afkbot`\n- **Version Code**: 1\n- **Version Name**: 1.0\n- **Architecture**: All (arm64-v8a, armeabi-v7a, x86, x86_64)\n\n## Legal Notice\n\n**This app is
